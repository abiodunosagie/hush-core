# Brand

Copies of the Hush logo for this repo's README and web demo. The masters, the generator and the
guidelines live in the [Hush repo](https://github.com/abiodunosagie/hush/tree/main/brand); change them there and copy them here.

`web/index.html` also inlines the wordmark path (so it can follow the page's light and dark colours). Update it with the SVGs.

`banner.png` is the README header and the GitHub social preview (1280x640).
